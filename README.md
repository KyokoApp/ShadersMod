# ShadersMod (MCPE / MagicLoader Optimized)

Kumpulan shader pack Minecraft Java (OptiFine/Iris) yang sudah dioptimasi khusus untuk **MagicLoader (Minecraft Bedrock Android)** dan diuji pada chipset **MediaTek Helio G99 (GPU Mali-G57 MC2)**.

## Shader Pilihan Terbaik untuk Helio G99

### 🌟 1. Miniature Shader (Helio G99 60FPS Edition) — **REKOMENDASI TERBAIK**
- **File**: `Miniature-HelioG99-60FPS.zip`
- **Download Langsung**: [Unduh Miniature-HelioG99-60FPS.zip](https://raw.githubusercontent.com/KyokoApp/ShadersMod/main/Miniature-HelioG99-60FPS.zip)
- **Karakteristik**:
  - Didesain dari awal dengan arsitektur **forward-rendering ringan** (tidak menggunakan heavy deferred multi-pass).
  - **Visual 100% Utuh**: Bayangan dinamis asli (real-time entity & block shadow), refleksi air Screen Space Reflection (SSR) dengan ombak realistis, gradien langit estetik, dan pencahayaan obor hangat.
  - **Optimasi Helio G99**: Shadow map disetel ke 512 + single-tap depth texture, raymarching step SSR disesuaikan ke rasio optimal Mali-G57 agar framerate stabil di 55–60 FPS tanpa menurunkan visual.
