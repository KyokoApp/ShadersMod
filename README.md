# ShadersMod (MCPE / MagicLoader Optimized for Helio G99)

Koleksi Shaderpack Minecraft Java (OptiFine/Iris) yang sudah dioptimasi khusus untuk **MagicLoader (Minecraft Bedrock Android)** dan disesuaikan dengan arsitektur GPU **Mali-G57 MC2 (MediaTek Helio G99)**.

---

## 🌟 BSL Shaders - Helio G99 Ultra Smooth Edition (Paling Direkomendasikan)
- **File**: `BSL-UltraSmooth-HelioG99.zip`
- **Download Langsung**: [Unduh BSL-UltraSmooth-HelioG99.zip](https://raw.githubusercontent.com/KyokoApp/ShadersMod/main/BSL-UltraSmooth-HelioG99.zip)
- **Visual 100% Tetap BSL Asli**:
  - Warna sinematik khas BSL yang estetik dan lembut.
  - Bayangan dinamis halus (*soft shadow filtering*).
  - Air jernih bergelombang dengan pantulan cahaya matahari.
  - Daun, rumput, dan tanaman bergoyang tertiup angin (*waving foliage*).
  - Langit, awan, dan pencahayaan obor hangat.
- **Optimasi Internal**:
  - Godrays/Light shafts raymarching dialihkan ke screen-space agar GPU Mali tidak panas.
  - TAA berat diganti FXAA agar gambar tetap tajam dan tidak ghosting saat kamera bergerak.
  - Jarak render bayangan disesuaikan ke 56 block (ideal untuk layar smartphone).

## Tips Setting di HP (Tanpa Perlu Modif APK / Bikin Addon)
Tidak perlu memodifikasi APK Minecraft atau memasang addon. Cukup atur setting video di dalam game:
1. **Render Distance (Jarak Pandang)**: Setel di **8 - 10 Chunks** (jangan 14+ chunks).
2. **Beautiful Skies & Smooth Lighting**: Biarkan **ON**.
3. **Graphics**: Setel ke **Fancy** (jangan Fabulous / Ray Tracing bawaan).
4. **Framerate Limit**: Setel ke **60 FPS** atau **Unlimited**.
