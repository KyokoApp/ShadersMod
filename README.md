# ShadersMod (MCPE / MagicLoader Optimized)

Kumpulan shader pack Minecraft Java (OptiFine/Iris) yang sudah dioptimasi khusus untuk **MagicLoader (Minecraft Bedrock Android)** agar stabil 60 FPS di layar HP.

## Daftar Shader

### 1. MakeUp - Ultra Fast (MCPE 60FPS Edition)
- **File**: `MakeUp-UltraFast-MCPE-60FPS.zip`
- **Download Langsung**: [Unduh MakeUp-UltraFast-MCPE-60FPS.zip](https://raw.githubusercontent.com/KyokoApp/ShadersMod/main/MakeUp-UltraFast-MCPE-60FPS.zip)
- **Fitur Optimasi**:
  - AO (Ambient Occlusion) dipangkas ke 2 steps (anti-drop di gua/hutan).
  - Volumetric Clouds step dioptimalkan ke 6 samples.
  - Planar water reflection (air bening bergelombang tanpa lag).
  - TAA diganti Fast Denoise/FXAA.
  - DoF/Motion Blur dimatikan untuk performa maksimal.
