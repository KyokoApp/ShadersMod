# ShadersMod (MCPE / MagicLoader Optimized)

Kumpulan shader pack Minecraft Java (OptiFine/Iris) yang sudah dioptimasi ekstrem khusus untuk **MagicLoader (Minecraft Bedrock Android)**.

## Pilihan Shader

### 1. MakeUp - Bedrock Extreme 60FPS (Rekomendasi Utama: 60 FPS Konstan)
- **File**: `MakeUp-Bedrock-Extreme60FPS.zip`
- **Download**: [Unduh MakeUp-Bedrock-Extreme60FPS.zip](https://raw.githubusercontent.com/KyokoApp/ShadersMod/main/MakeUp-Bedrock-Extreme60FPS.zip)
- **Visual**: Air bening bergelombang realistis, tanaman/daun bergoyang, pencahayaan hangat, langit dan matahari HD.
- **Performa**: Shadow pass berat dimatikan total. GPU HP tidak dirender dua kali. FPS langsung melompat dari 15 FPS ke 60 FPS stabil tanpa panas.

---

### 2. MakeUp - Bedrock SoftShadow 60FPS (Tetap Ada Bayangan Realistis)
- **File**: `MakeUp-Bedrock-SoftShadow60FPS.zip`
- **Download**: [Unduh MakeUp-Bedrock-SoftShadow60FPS.zip](https://raw.githubusercontent.com/KyokoApp/ShadersMod/main/MakeUp-Bedrock-SoftShadow60FPS.zip)
- **Visual**: Semua efek di atas + **bayangan pohon, bangunan, dan karakter**.
- **Performa**: Shadow map diperkecil ke 256, sampling loop 4x dipangkas jadi 1-tap hardware texture. Jauh lebih enteng daripada bawaan PC.
